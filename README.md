## Current version: 0.1.1

GeoFS-MXWL-Analog is a VHS shader for GeoFS

The shader still looks good in low graphics settings

### This is not an HUD overlay so it only works with GeoFS 3.9 as it uses its shader language

## Features:

- **Bloom / Halation**
- **Chroma Smear**
- **Low Dynamic Range**
- **Chroma Noise**
- **Horizontal Softness**
- **Edge Ringing**
- **Tracking Lines**
- **Head-Switch Noise**
- **Horizontal Jitter**
- **Luma Grain**
- **Smear Noise**
- **Comet Tails**

Each and every one of them can be edited or disabled.

One thing to keep in mind:

The bloom can make your game very bright in daytime. So adjust the "Threshold" under the main bloom option (0 at night and 100 during daytime)
